AI Chat Exporter

One bookmarklet for ChatGPT, Claude, Gemini, grok.com, and Grok on X. Exports the current conversation as Markdown or JSON, with speakers, timestamps when the site exposes them, title/project, and an export clock so you can diff two dumps of the same thread.

Install: drag this button onto your bookmarks bar.

Export Chat

If drag-and-drop is blocked, create a bookmark manually and paste the URL from the box below.

Use
  1. Open a conversation on chatgpt.com, claude.ai, gemini.google.com, grok.com, or x.com/i/grok.
  2. Click Export Chat.
  3. Wait while it scrolls the thread (long chats load turns on demand).
  4. Choose Markdown or JSON. The file lands in Downloads.

Nothing is uploaded. The script runs in the page and talks only to that site’s own APIs, using your existing login cookie.

If the bookmarklet is blocked

Claude and a few other sites use a Content Security Policy that can refuse javascript: bookmarks. Open DevTools → Console, paste the contents of chat-export.js, press Enter.
